# Norte Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Native macOS Kanban+agenda app and iOS agenda app (with lock-screen widgets), synced through the user's Google account via EventKit — zero backend, zero cost.

**Architecture:** One XcodeGen-generated project with three app targets (Norte-macOS, Norte-iOS, NorteWidgets) sharing a local SwiftPM package `NorteKit` (models, mirror-sync engine, EventKit service, design tokens). Tasks persist in SwiftData on the Mac only; tasks with deadlines are mirrored as events into a dedicated "📋 Tarefas" Google calendar, which the iPhone reads via the system calendar.

**Tech Stack:** Swift 6.3, SwiftUI, SwiftData, EventKit, WidgetKit, XcodeGen, swift-testing (SwiftPM tests).

**Spec:** `docs/superpowers/specs/2026-09-07-norte-design.md`

## Global Constraints

- Deployment targets: macOS 26, iOS 26 (user runs Tahoe 26 / iOS 26).
- No third-party runtime dependencies. No network code. All external data via EventKit.
- macOS signing: `CODE_SIGN_IDENTITY=-` (Sign to Run Locally). iOS signing: personal team via Xcode automatic signing (user selects team once in Xcode).
- Contexts (fixed enum, exact display names): `IA Solutions`, `Chai School`, `Nath Pereira`, `Faculdade`, `Pessoal`.
- Kanban columns (exact order): Backlog, A Fazer, Fazendo, Feito.
- Urgency emoji mapping: alta=🔴, média=🟡, baixa=🟢.
- Mirror calendar name: `📋 Tarefas`. Reconciliation marker in event notes: `norte-task-id: <UUID>`.
- All user-facing copy in pt-BR.
- Type name for the task model is `NorteTask` (avoid clash with Swift concurrency `Task`).

### Task 2: Mirror sync engine (pure logic, TDD)

**Files:**
- Create: `NorteKit/Sources/NorteKit/MirrorSync.swift`
- Test: `NorteKit/Tests/NorteKitTests/MirrorSyncTests.swift`

**Interfaces:**
- Produces:
  ```swift
  public struct MirrorItem: Equatable { public var eventID: String; public var taskID: UUID; public var title: String; public var deadline: Date; public var isAllDay: Bool }
  public struct TaskSnapshot { public var id: UUID; public var title: String; public var urgency: Urgency; public var status: TaskStatus; public var deadline: Date?; public var deadlineIsAllDay: Bool }
  public enum MirrorAction: Equatable { case create(taskID: UUID, title: String, deadline: Date, isAllDay: Bool)
                                        case update(eventID: String, title: String, deadline: Date, isAllDay: Bool)
                                        case delete(eventID: String) }
  public enum MirrorPlanner { public static func plan(tasks: [TaskSnapshot], existing: [MirrorItem]) -> [MirrorAction] }
  ```
- Rules under test: task w/ deadline & status != done & no mirror → create with title `"\(urgency.emoji) \(title)"`; existing mirror w/ drifted title/deadline → update; task done, deadline removed, or task deleted (orphan event) → delete; unchanged → no action; duplicate events for same taskID → keep first, delete rest (idempotency).

- [ ] Steps: write the rule tests above with concrete fixtures; run (fail); implement `MirrorPlanner.plan` as pure diff; run (pass); commit `feat: mirror sync planner`.

### Task 5: EventKit service + calendar bootstrap

**Files:**
- Create: `NorteKit/Sources/NorteKit/CalendarService.swift` (protocol + EventKit implementation)

**Interfaces:**
- Produces:
  ```swift
  public protocol CalendarServicing {
      func requestAccess() async throws -> Bool
      func googleSourceAvailable() -> Bool
      func ensureCalendars() throws  // creates 5 context calendars + 📋 Tarefas, idempotent by title
      func events(from: Date, to: Date) throws -> [CalendarEventData]
      func mirrorItems() throws -> [MirrorItem]
      func apply(_ actions: [MirrorAction]) throws
  }
  public final class EventKitCalendarService: CalendarServicing { public init() }
  ```
- Google source detection: `EKSource` of type `.calDAV` whose title contains "gmail"/"google" (case-insensitive); fallback to any calDAV source; final fallback local source (still works, just doesn't sync — surfaced in UI).
- Mirror events carry `norte-task-id: <uuid>` as first line of `notes`; `mirrorItems()` parses it.

- [ ] Steps: implement; unit-test the notes-parsing helpers (pure funcs) in NorteKitTests; `swift test` passes; both apps still build; commit `feat: EventKit service`.
